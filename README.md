# Videoscop

## Описание

Videoscop — это сервис для управления пользователями, видео и тепловыми картами. Он предоставляет функционал для создания, обновления, удаления и получения данных пользователей, а также для работы с видео и тепловыми картами.

### Основные возможности:

- Управление пользователями: создание, обновление, удаление и получение данных.
- Работа с видео: создание, поиск, получение ссылок на загрузку и выгрузку.
- Работа с тепловыми картами: создание и получение ссылок на выгрузку.

## Backend

### Архитектура

Бэкенд построен на основе архитектуры REST API и организован по принципу модульности. Основные компоненты включают:

1. **Контроллеры (Handlers)**: Обрабатывают HTTP-запросы, вызывают соответствующие интеракторы и возвращают ответы клиенту.
2. **Интеракторы (Interactors)**: Реализуют бизнес-логику приложения, взаимодействуют с репозиториями, валидаторами и другими компонентами.
3. **Репозитории (Repositories)**: Отвечают за доступ к данным в базе данных, включая выполнение CRUD-операций.
4. **Модели (Models)**: Определяют структуру данных и схемы базы данных.
5. **Валидаторы (Validators)**: Проверяют корректность входных данных.
6. **Инфраструктура (Infrastructure)**: Содержит компоненты для работы с базой данных, файловым хранилищем и авторизацией.
7. **Конфигурация (Config)**: Управляет настройками приложения, включая параметры базы данных, авторизации и файлового хранилища.
8. **Обработка ошибок (Exception Handlers)**: Централизованно обрабатывает ошибки, возникающие в процессе работы приложения.

### Компоненты

- **API**: REST API предоставляет интерфейс для взаимодействия с клиентом.
- **База данных**: PostgreSQL используется для хранения данных пользователей, видео и тепловых карт.
- **Файловое хранилище**: MinIO используется для загрузки и выгрузки видео и тепловых карт.
- **Авторизация**: JWT обеспечивает управление доступом пользователей.
- **Миграции**: Alembic используется для управления схемой базы данных.

### Структура проекта

- `backend/api/v1/adapters`: Содержит контроллеры (handlers), схемы запросов и ответов, а также обработчики ошибок.
- `backend/api/v1/application`: Реализует бизнес-логику (интеракторы), DTO и интерфейсы.
- `backend/api/v1/domen`: Определяет сущности (entities), используемые в приложении.
- `backend/api/v1/infrastructure`: Содержит компоненты для работы с базой данных, файловым хранилищем и авторизацией.
- `backend/api/v1/config.py`: Содержит настройки приложения.
- `backend/api/v1/main.py`: Точка входа для запуска приложения.
- `docker/backend`: Содержит Dockerfile и docker-compose.yml для контейнеризации приложения.

### Установка и запуск

#### Требования

- Docker
- Docker Compose

#### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL репозитория>
   cd videoscop
   ```

#### Запуск через Docker

1. Перейдите в каталог `docker/backend`:

   ```bash
   cd docker/backend
   ```
2. Соберите и запустите контейнеры:

   ```bash
   docker-compose up --build
   ```
3. Для передачи переменных окружения используйте файл `.env`. Пример:

   ```bash
   docker-compose --env-file .env up --build
   ```
4. API будет доступно по адресу:

   ```
   http://127.0.0.1:8000
   ```

#### Тестирование

Для запуска тестов внутри контейнера выполните:

```bash
docker exec -it <container_name> pytest backend/api/v1
```

#### Документация API

Документация доступна по адресу:

```
http://127.0.0.1:8000/docs
```

#### Пример использования

Пример использования API можно найти в файле `curl_test.sh`, который содержит скрипт для выполнения основных операций через curl.

### Шаблон файла `.env`

В проекте доступен файл `.env.template`, который содержит список всех необходимых переменных окружения. Скопируйте его и заполните:

```bash
cp .env.template .env
```

## Frontend

### Описание

Фронтенд реализует пользовательский интерфейс для работы с сервисом Videoscop. Он позволяет пользователям:
- проходить калибровку трекера взгляда,
- загружать и просматривать видео,
- просматривать тепловые карты,
- управлять сессиями и профилем,
- взаимодействовать с основными функциями сервиса через современный web-интерфейс.

### Технологии

- **HTML, CSS, JavaScript** — основа интерфейса.
- **Bootstrap 5** — для адаптивной вёрстки и UI-компонентов.
- **WebGazer.js** — для трекинга взгляда.
- **SimpleHeat** — для визуализации тепловых карт.
- **SweetAlert** — для всплывающих уведомлений.

### Структура проекта

- `frontend/index.html`, `frontend/home.html`, `frontend/player.html` — основные страницы приложения.
- `frontend/styles/` — стили для страниц (CSS/SCSS).
- `frontend/www/js/` — скрипты для работы с калибровкой, тепловыми картами, загрузкой видео и др.
- `frontend/public/` — иконки, изображения и логотипы.
- `frontend/www/media/` — примеры медиафайлов для тестирования.
- `frontend/package.json` — зависимости для фронтенда (если используются сборщики или npm-пакеты).

### Запуск

1. Перейдите в папку `frontend`:
   ```bash
   cd frontend
   ```
2. Откройте файл `index.html` или `home.html` в браузере (двойной клик или через локальный сервер, например, Live Server для VSCode).

#### Для разработки с использованием npm (если требуется):

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите локальный сервер (например, с помощью [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) или через встроенный скрипт):
   ```bash
   npm start
   ```

### Взаимодействие с backend

Фронтенд отправляет HTTP-запросы к backend API для получения и отправки данных пользователей, видео и тепловых карт. Адрес backend указывается в настройках или переменных окружения (если используется).
